Software Design and Engineering

The first enhancement focused on improving the structure, maintainability, usability, and reliability of IVTRK.

Algorithms and Data Structures

The second enhancement focused on improving how inventory data is searched, sorted, grouped, and prioritized.

The enhancement used structures such as ArrayList, HashMap, Comparator, and PriorityQueue to support sorting, filtering, grouping, and restock prioritization.

Databases

The database enhancement expanded the original SQLite database so inventory activity could be preserved instead of only storing the current quantity.

The enhanced database records inventory additions, quantity changes, deletions, timestamps, and usernames. Database migrations and transactions were also added to preserve data and improve consistency.
